## 🚀 Projects & Contributions

### 🎮 [LibreGaming](https://github.com/ahmed-al-balochi/LibreGaming) · _Creator_
A Python program that installs the gaming packages your Linux distribution needs — Steam, Wine-Staging, Gamemode, Lutris, MangoHud and more. Works on Ubuntu, Arch, Fedora and OpenSUSE Tumbleweed, with both a CLI and a Qt GUI.
